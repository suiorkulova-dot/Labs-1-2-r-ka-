# Жизненный цикл запроса

## Сценарий UC2: Прогнозирование стоимости аренды недвижимости

### Шаг 1. Действие пользователя

Пользователь открывает страницу прогнозирования стоимости аренды, вводит город, район, площадь квартиры, количество комнат и доступные удобства. После нажатия кнопки «Рассчитать стоимость» Frontend отправляет запрос на сервер.

### Шаг 2. DNS

Браузер определяет IP-адрес сервера приложения с помощью DNS. Это позволяет установить соединение с сервером по доменному имени.

### Шаг 3. Установка соединения

Браузер устанавливает соединение с сервером. При использовании HTTPS устанавливается защищённое соединение TLS для шифрования передаваемых данных.

### Шаг 4. HTTP-запрос

Frontend отправляет POST-запрос по адресу `/api/predictions`. Данные передаются в формате JSON с заголовком `Content-Type: application/json`.

Пример тела запроса:

```json
{
  "city": "Бишкек",
  "district": "Центр",
  "area": 60,
  "rooms": 2,
  "furnished": true
}
```

### Шаг 5. Приём запроса

Backend на Python и FastAPI принимает запрос по адресу `/api/predictions` и передаёт его на обработку соответствующему модулю.

### Шаг 6. Обработка в Backend

Сервер проверяет корректность характеристик недвижимости. Модуль Prediction подготавливает данные и передаёт их обученной модели машинного обучения для расчёта прогнозируемой стоимости аренды.

### Шаг 7. Обращение к базе данных

При необходимости Backend получает из PostgreSQL дополнительные сведения о ценах, характеристиках недвижимости и истории изменения стоимости аренды. Эти данные могут использоваться для анализа рынка и подготовки прогноза.

### Шаг 8. Ответ сервера

После расчёта Backend возвращает ответ со статусом `200 OK` в формате JSON.

Пример ответа:

```json
{
  "predicted_price": 35000,
  "currency": "KGS"
}
```

Указанная сумма является условным примером, а не результатом реально обученной модели.

### Шаг 9. Обновление интерфейса

Frontend получает ответ сервера и отображает пользователю прогнозируемую стоимость аренды. Пользователь может сравнить полученную оценку с ценами аналогичных объектов недвижимости.
